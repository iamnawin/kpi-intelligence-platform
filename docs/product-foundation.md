# ProofPath

## Tagline
Portable, evidence-backed performance intelligence for modern work.

## One-Line Description
ProofPath is an AI-native performance intelligence platform that connects goals, tasks, outcomes, and evidence into a permissioned system that helps companies understand contribution and helps individuals carry verified proof of their work across roles and careers.

---

## Vision
Work happens across many systems, but meaningful proof of contribution gets lost.

ProofPath exists to solve that gap by creating a trusted performance layer above existing tools, where goals, subtasks, outcomes, comments, metrics, and evidence are mapped into a structured graph that can power:

- company performance insight
- manager decision-making
- employee coaching
- verified achievement records
- portable career proof

---

## Core Problem

### Current Reality
Most companies already use tools for:
- project tracking
- task management
- OKRs and goals
- KPIs and reporting
- feedback and reviews
- CRM and service metrics
- spreadsheets and notes

These tools track fragments of work, but they do not answer the bigger questions:

- What did this person actually contribute?
- How did their work connect to team and company goals?
- What evidence proves that contribution?
- What outcomes changed because of that work?
- How can that work be carried forward into a promotion, internal move, or new career opportunity?

### The Gap
Today, when employees move roles or leave a company, most of their real work history disappears into:
- tickets
- dashboards
- comments
- manager memory
- scattered files
- disconnected systems

This creates a trust and continuity gap for both:
- companies
- individuals

ProofPath fills that gap.

## Product Principles

### 1. Evidence Over Opinion
Performance should be supported by linked outcomes, artifacts, metrics, and approved records wherever possible.

### 2. Work Should Be Portable
A person’s meaningful work history should not disappear just because tools change or employment changes.

### 3. AI Must Be Grounded
AI should interpret real data and evidence, not invent flattering or vague narratives.

### 4. Permission First
Not all work can or should be portable. The system must separate company-owned context from approved user-portable proof.

### 5. Existing Tools Stay
ProofPath should work with the tools companies already use instead of forcing complete replacement from day one.

### 6. Numbers and Narrative Both Matter
Performance is not only metrics. It also includes context, complexity, ownership, collaboration, and visible impact.

## Security and Ownership Model

### Company-Owned Data
Includes:
- internal goal structures
- private team data
- sensitive project context
- restricted feedback
- confidential performance notes

### User-Portable Data
Includes only approved subsets such as:
- verified achievements
- approved contribution summaries
- selected evidence artifacts
- role-based outcome highlights
- sanitized KPI or performance proof

### Rules
- portability must be permissioned
- export must be reviewable
- users should not automatically carry confidential company data
- company admins define boundaries
- audit trails must exist for exports and approvals

### Manager Journey
1. Manager imports or defines goals and team structure

3. Dashboard shows team progress and contribution signals

3. AI explains current progress and suggests focus areas
4. Employee reviews contribution history and evidence
