## 7. Trust & Guardrails System

ProofPath must not treat all data equally.

Instead, it shows **trust levels**.

---

### Trust Levels

| Level | Name | Description |
|------|------|------------|
| 0 | Draft | Not submitted |
| 1 | Self-Reported | Manual input |
| 2 | Imported | File upload |
| 3 | Reviewer Approved | Manager validated |
| 4 | System Verified | Integrated system data |
| 5 | Locked Proof | Tamper-proof verified record |

---

### Trust Principles

- no false equivalence between manual and verified data  
- every record shows trust level  
- more evidence = higher trust  
- integrations increase credibility  
- portability is permission-based  

---

### Trust Metadata Per Record

Each record includes:
- source type  
- uploader  
- reviewer  
- evidence links  
- system connections  
- validation level  
- confidence score  
- lock status  

---

### Guardrail Philosophy

ProofPath does not say:
> “this is true”

It says:
> “this is how trustworthy this is”
